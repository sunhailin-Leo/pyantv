
# Features

> Last updated: 2026-04-23（同步至 Sprint 73）

## Completed Features

### Core (Sprint 29-36)
- [x] Input validation and friendly error messages
- [x] Annotation system (LineAnnotation, RegionAnnotation, TextAnnotation)
- [x] Data transformation enhancements
- [x] Streamlit integration
- [x] Chart export to PNG/SVG (Playwright)
- [x] CI/CD enhancements + PyPI publishing
- [x] Changelog + Documentation site foundation

### Charts
- [x] Support [3D Chart](https://g2.antv.antgroup.com/manual/extra-topics/three-dimensional/draw-threed-chart) (Point3D, Line3D, Interval3D)
- [x] Advanced chart wrappers: Funnel, WaterFall, Bullet
- [x] Basic chart extensions: Partition, Beeswarm
- [x] 44 chart types across 8 categories (statistical / distribution / relational / geographic / special / 3D / composite / basic marks)
- [x] Support Plugin
  - [x] [render plugin](https://g2.antv.antgroup.com/manual/extra-topics/plugin/renderer)
  - [x] [rough plugin](https://g2.antv.antgroup.com/manual/extra-topics/plugin/rough)
  - [x] [lottie plugin](https://g2.antv.antgroup.com/manual/extra-topics/plugin/lottie)

### Developer Experience
- [x] Event system: 90+ G2 event constants + `set_events()` API
- [x] Preset system: 31 preset functions (themes, animation, layout, coordinate, interaction, data transform, formatting)
- [x] Shortcut methods: `from_data()`, `from_dataframe()`, `set_title()`, `set_padding()`, `set_size()`
- [x] Top-level exports: `ChartEvent`, `JsCode`, `presets` importable from `pyantv`
- [x] Batch export: `batch_export_png()` for multi-chart export
- [x] Type stub files (.pyi) for IDE autocompletion (auto-generated by `scripts/gen_type_stubs.py`)

### Packaging & CI/CD (Sprint 62, 67, 69, 72)
- [x] `pyproject.toml` migration (single source of truth, PEP 517/621)
- [x] `uv` as official dependency manager (CI 同构)
- [x] Coverage gate: `--cov-fail-under=95` enforced in CI
- [x] Property-based testing via Hypothesis (3 profiles: dev/ci/exhaustive)
- [x] Version management with `setuptools-scm` + git tag (auto-derived versions)
- [x] Automated PyPI release workflow on tag push (`.github/workflows/release.yml`)

### Performance & Big Data (Sprint 64, 66)
- [x] Downsampling: LTTB / uniform / random for large datasets
- [x] Compact JSON serialization (≥40% HTML size reduction)
- [x] Performance baselines with CI tier (local 500ms / CI 800ms thresholds)
- [x] Visual regression testing (dual-track: pixel + SSIM with anti-aliasing edge mask)

### Offline & Notebook (Sprint 63, 71, 73)
- [x] Offline asset management (`pyantv.offline` module, `install_assets()`, `set_offline_host()`)
- [x] Interactive documentation site with chart gallery (`docs/charts/`, `docs/presets/`, `docs/options/`)
- [x] Colab + Binder badges, `notebooks/quickstart.ipynb`
- [x] Chart documentation auto-generation (`scripts/gen_chart_docs.py`, 44 chart pages)
- [x] Jupyter Notebook deep integration (`_repr_html_`, `notebook_config()`, Colab/Binder/VS Code support)

### Community & Discoverability (Sprint 68, 70)
- [x] Gallery preview image (`docs/assets/gallery_preview.png`)
- [x] Issue Forms (bug / feature / docs / config) + structured PR template
- [x] Comparison doc (`docs/comparison.md`) vs pyecharts / py-vchart
- [x] CONTRIBUTING.md + Good First Issues list
- [x] Doc screenshot script + chart documentation `--check` mode
