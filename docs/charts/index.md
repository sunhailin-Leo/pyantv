# 图表总览

pyantv 提供了丰富的图表类型，涵盖统计图表、分布图、关系图、地理图、特殊图、3D 图表、组合图表和基础标记等 8 大类，共 44 种图表类型。

## 统计图表

用于展示数据的统计特征和趋势变化。

- [Line](line.md) - 折线图
- [Area](area.md) - 面积图
- [Interval](interval.md) - 区间图
- [Point](point.md) - 散点图

## 分布图

用于展示数据的分布特征。

- [Boxplot](boxplot.md) - 箱线图
- [Density](density.md) - 密度图
- [Beeswarm](beeswarm.md) - 蜂群图

## 关系图

用于展示数据之间的关系和层次结构。

- [Sankey](sankey.md) - 桑基图
- [Chord](chord.md) - 弦图
- [Force Graph](force_graph.md) - 力导向图
- [Treemap](treemap.md) - 矩形树图
- [Tree](tree.md) - 树图
- [Pack](pack.md) - 打包图
- [Partition](partition.md) - 分区图

## 地理图

用于展示地理空间数据。

- [Geo Path](geo_path.md) - 地理路径图
- [Geo View](geo_view.md) - 地理视图

## 特殊图

用于特定场景的数据可视化。

- [Gauge](gauge.md) - 仪表盘
- [Liquid](liquid.md) - 水波图
- [Wordcloud](wordcloud.md) - 词云图
- [Funnel](funnel.md) - 漏斗图
- [Waterfall](waterfall.md) - 瀑布图
- [Bullet](bullet.md) - 子弹图

## 3D 图表

用于展示三维空间数据。

- [Point3D](point3d.md) - 3D 散点图
- [Line3D](line3d.md) - 3D 折线图
- [Interval3D](interval3d.md) - 3D 区间图

## 组合图表

用于展示多维数据或组合多个图表。

- [Facet Circle](facet_circle.md) - 圆形分面
- [Facet Rect](facet_rect.md) - 矩形分面
- [Space Flex](space_flex.md) - 弹性空间布局
- [Space Layer](space_layer.md) - 图层叠加布局
- [Repeat Matrix](repeat_matrix.md) - 重复矩阵
- [Timing Key Frame](timing_key_frame.md) - 时间关键帧
- [View](view.md) - 视图容器

用于构建自定义图表的基础图形元素。

- [Rect](rect.md) - 矩形
- [Cell](cell.md) - 单元格
- [Link](link.md) - 链接
- [Arc](arc.md) - 弧线
- [Text](text.md) - 文本
- [Path](path.md) - 路径
- [Shape](shape.md) - 形状
- [Connector](connector.md) - 连接器
- [Range](range.md) - 范围
- [Image](image.md) - 图片
- [Polygon](polygon.md) - 多边形
- [Vector](vector.md) - 矢量
- [Heatmap](heatmap.md) - 热力图
- [Box](box.md) - 箱形
